# FastWeb AI Agent

LLM-агент, который генерирует лендинги и многостраничные сайты 
по текстовому запросу. Работает в чате: пишете задачу — агент 
создаёт файлы проекта в `workspace/` и показывает превью.

## Возможности
- Чат-интерфейс с потоковым ответом (SSE)
- Инструменты агента: создание папок, запись/правка файлов, 
  валидация HTML, семантический поиск по проекту (Qdrant)
- Память по проектам: каждый проект индексируется отдельно
- Стоимость каждого шага в реальном времени, CSV-лог
- Выбор модели, лимиты шагов/токенов/бюджета
- Тёмная/светлая тема, экспорт лога диалога

## Стек
- Python 3.12, FastAPI, OpenAI SDK (DeepSeek API)
- Qdrant + sentence-transformers (векторная память)
- Vanilla JS + marked.js (фронтенд чата)
- Docker Compose (агент + qdrant)

## Быстрый старт
```bash
cp .env.example .env
# вписать DEEPSEEK_API_KEY
docker compose up --build
# Открыть
http://localhost:8000
```

## Как это работает
- Пользователь пишет задачу в чат
- Сервер передаёт запрос модели с описанием инструментов
- Модель вызывает tools (write_file, edit_file...)
- Файлы пишутся в workspace/<проект>/
- Превью: /preview/<проект>/index.html
- Изменённые файлы индексируются в Qdrant для поиска

## Структура
- core/ — сервер, клиент LLM, память
- primitives/ — инструменты агента, валидаторы
- prompts/ — системный промпт
- configs/ — настройки
- workspace/ — генерируемые проекты
