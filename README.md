# FastWeb AI Agent

LLM-агент, который генерирует лендинги и многостраничные сайты по текстовому запросу. Работает в чате: пишете задачу — агент создаёт файлы проекта в `workspace/`, генерирует изображения для сайта и показывает превью.

## Возможности
- Чат-интерфейс с потоковым ответом (SSE)
- Генерация изображений (FLUX) через Fal.ai с контролем размера и стоимости
- Инструменты агента: создание папок, запись/правка файлов, валидация HTML, семантический поиск по проекту (Qdrant)
- Память по проектам: каждый проект индексируется отдельно
- Стоимость каждого шага в реальном времени, CSV-лог
- Выбор модели, лимиты шагов/токенов/бюджета
- Тёмная/светлая тема, экспорт лога диалога

## Стек
- Python 3.12, FastAPI, OpenAI SDK (DeepSeek API)
- Qdrant + sentence-transformers (векторная память)
- Fal.ai (FLUX.1 Schnell API для генерации картинок)
- Vanilla JS + marked.js (фронтенд чата)
- Docker Compose (агент + qdrant)

## Быстрый старт
```bash
cp .env.example .env
# вписать DEEPSEEK_API_KEY и FAL_API_KEY
docker compose up --build
```
После запуска открыть: http://localhost:8000

## Как это работает
Пользователь пишет задачу в чат
Сервер передаёт запрос модели с описанием инструментов
Модель вызывает tools (write_file, edit_file, generate_image и др.)
Текстовые файлы пишутся в workspace/<проект>/
Картинки генерируются нейросетью FLUX и сохраняются в workspace/<проект>/images/
Превью: /preview/<проект>/index.html
Изменённые файлы индексируются в Qdrant для поиска

## Структура
core/ — сервер, клиент LLM, память
primitives/ — инструменты агента, валидаторы
prompts/ — системный промпт
configs/ — настройки
workspace/ — генерируемые проекты
